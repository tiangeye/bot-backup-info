Privacy notice

Last updated 8 November 2026.

This privacy notice is the privacy policy for Bot Backup, a personal desktop application maintained by Tiange Ye. The homepage links here. Bot Backup is not offered as a service to other people. The owner uses it with his own Google account.

Google Drive access

Bot Backup runs rclone on a schedule. It copies the owner's non-secret bot configuration and work state to his own Google Drive. Google Drive access is used only so he can manage those backups and check or restore them.

rclone may request Google's full Drive scope, https://www.googleapis.com/auth/drive. With that scope, a Google authorization can reach files outside a single folder and is not limited to files created by one application. This notice does not describe the access as the narrower drive.file scope, and it does not claim a single-folder limit.

The owner does not sell this access and does not use it for advertising.

What this website does

This website is static information about that utility. It does not run the backups. Visiting it does not request OAuth and does not collect Google Drive data.

The pages do not:

  • ask anyone to sign in with Google
  • start an OAuth flow or act as an OAuth redirect address
  • receive authorization codes or tokens
  • read, store, or display Drive files
  • include a form, account, or mailing list
  • load analytics, advertising, or other third-party scripts
  • set their own cookies

GitHub Pages hosts the files. Request logs, if GitHub keeps them, are handled by GitHub under the GitHub General Privacy Statement.

Credentials

OAuth client credentials, tokens, and the rclone configuration stay on the owner's own computers. They are kept outside this website and outside this public repository.

Retention and revoking access

The owner controls which files are backed up and how long those copies remain in his Google Drive. He can delete them in Drive.

He can revoke Bot Backup's Google access from his Google Account on Google's third-party access page. Revoking that grant stops further access with it. Revoking access does not by itself delete files already stored in Drive. Google's handling of account and Drive data is described in Google's Privacy Policy.

Selling and advertising

Google account access and backup contents are not sold. They are not used for advertising and they are not used to build advertising profiles.

Google, GitHub, and limits of this notice

Google operates Google Drive. GitHub operates GitHub Pages, which serves these pages. Each service applies its own terms and privacy policy to infrastructure it runs.

This notice does not claim that Bot Backup encrypts backups, that Drive access is limited to one folder or to the drive.file scope, or that data held or transmitted by Google or GitHub is inaccessible to those services.

Contact

Questions about this notice can be opened as an issue in the public repository: github.com/tiangeye/bot-backup-info/issues.

Do not include private information in an issue. That includes passwords, OAuth client secrets, tokens, rclone configuration, and backup contents. Issues are public.

Changes

If this notice changes, the updated text will be published at this same page with a new date.
