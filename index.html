Bot Backup

Bot Backup is a personal desktop application maintained by Tiange Ye. He uses rclone on a schedule to copy his own non-secret bot configuration and work state to his own Google Drive.

Read the privacy notice. That page is the privacy policy for this application.

At a glance

Owner
Tiange Ye
Application
Bot Backup, a personal Google OAuth desktop utility
What is copied
His own non-secret bot configuration and work state
Where it goes
His own Google Drive, so he can keep, check, and restore those backups
This website
A public description and privacy notice. It does not sign anyone in and it does not hold backup files.

What this website is

These pages exist so the application has a public homepage and privacy notice. The site is not the backup program. It is not a sign-in page, and it is not an OAuth redirect address. Opening it does not start a Google sign-in, does not request Drive access, and does not show backup data.

Google Drive

When the owner runs Bot Backup on his own computer, Google Drive access is used only so he can manage his own backups and check or restore them. rclone may request Google's full Drive scope, https://www.googleapis.com/auth/drive. This site does not describe that access as the narrower drive.file scope, and it does not say the grant is limited to one folder.

OAuth client credentials, tokens, and the rclone configuration stay on the owner's computers. They are not published here.
